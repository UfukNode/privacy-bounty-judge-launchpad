Assignment flow

What participants should build

  1. Fork the starter repo. Work in your own copy of cozfuttu/ritual-chain-workshop.
  2. Replace plaintext submissions. Use submitCommitment during the submission phase.
  3. Reveal after the deadline. Verify answer, salt, sender, and bounty ID before storing the answer.
  4. Judge only valid reveals. Batch revealed answers into one Ritual LLM request.
  5. Let the owner finalize. AI review is advisory; the human owner transfers the reward.
Study-guide boundary: this repo explains the pattern and provides local helpers. It is not an official Ritual resource and it is not a one-click assignment solver.
